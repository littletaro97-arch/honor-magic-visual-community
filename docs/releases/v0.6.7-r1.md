# Magic 视界社区版 v0.6.7-r1

适用于 Windows 11 x64。此预发布修复 v0.6.7 在卸载时弹出 `Cannot call "WizardSilent" function during Uninstall` 的问题。

## 下载与安装

- [完整安装 ZIP](https://github.com/littletaro97-arch/honor-magic-visual-community/releases/download/v0.6.7-r1/MagicCommunity-Setup-0.6.7-r1-x64.zip) 包含一键安装器、安装与验收说明、更新说明、社区群二维码、第三方许可和校验清单。解压后运行包内的 EXE。
- [一键安装程序](https://github.com/littletaro97-arch/honor-magic-visual-community/releases/download/v0.6.7-r1/MagicCommunity-Setup-0.6.7-x64-unsigned-r1.exe) 可直接运行。安装向导会请求管理员权限，无需导入证书。
- [SHA-256 校验清单](https://github.com/littletaro97-arch/honor-magic-visual-community/releases/download/v0.6.7-r1/SHA256SUMS.txt) 可校验这两个下载文件。

已有 v0.6.7 的用户，关闭旧卸载报错窗口后运行 r1 安装器，沿用原目录覆盖安装。安装完成后，从 **Windows 设置 → 应用 → 已安装的应用** 选择卸载。希望保留布局、卡片和反馈数据时，在社区版的卸载提示中选择「是」。Windows 应用列表仍会显示 0.6.7。

## 本版改动

- 修复卸载入口调用安装向导的静默检查，覆盖安装会更新卸载程序。
- v0.6.7 基于 v0.6.6r3，带来玻璃材质、桌面拖放落位过渡、定时电源面板输入框对齐、Dock 右键过渡和音乐预览间距调整。

## 验证

在隔离目录复现旧版报错，并验证同版本覆盖安装后可以正常卸载。安装器的四项只读预检通过，应用载荷的 1,495 个文件与 v0.6.7 一致。实际桌面安装与卸载以真机验收为准。
