# v0.5.1 公开源码与安装包

本标签继续沿用公开仓库既有源码快照结构和许可证说明。产品源码对应本地构建提交 `06de21b23d8f8e77a8f4fb4f183d96c114a0b38d`，以已提交内容导出；没有公开本地开发历史、运行配置、用户反馈附件或内存管理实验。

从 v0.4.9 到 v0.5.1 的主要变化包括：安装路径与账户数据清理/恢复、外接主屏睡眠后的布局保护、窗口与托盘唤起、右键菜单兼容、图标读取和缓存、托盘拖动与动画，以及设置中的开机自启入口。v0.5.1 另外修复了 Dock 文件资源管理器误唤起蓝牙功能和顶栏托盘双击遗漏。

安装包使用已经构建并校验的原始 EXE，SHA-256 为 `6277D52580915476CABE1BCACF9B26B44A8B685CAF44085C6F395CA32048FDE3`。公开 ZIP 额外附带公开仓库现行许可证资料，不改动安装器二进制；ZIP 校验值见 Release 的 `SHA256SUMS.txt`。
