# 社区版荣耀图标资产

用户指定库的静态图标已收入本目录，作为社区版内置图标的优先资产源。均为普通文件，运行时不再访问外部 WorkBuddy 路径或荣耀原程序。

- 设置：社区版设置 → 外观 → 图标套装；荣耀·白底 / 荣耀·通透。选择立即通知现有原生宿主，保存于 ui-preferences.json，重开后保持。
- 资源：396 个原始静态文件（含 150 个 TopBar SVG）；不导入动画帧及动画大图。runtime-files.json 只列225个所需PNG，SVG编译进原生宿主。
- 自动匹配：catalog.json 登记110项应用；后台解析快捷方式真实目标、明确的包身份和 Steam AppID 后准确匹配，大小写不敏感；不再把快捷方式显示名称当作应用身份。Code/vscode、AUTOCAD 两套不同文件名有明确配对；缺少另套原件的项目使用登记的同库素材。窗口标题、部分进程名、普通文档不用于猜测应用身份。
- 桌面、大文件夹、开始菜单、原生顶栏与Dock：固定应用、开始、桌面、回收站及电池、音量、蓝牙、Wi-Fi等模块使用此资源。系统状态保留原有数据和操作；回收站复用现有Shell通知，不增加监听。动态图标/未收录第三方应用与自定义图标保留原来源。
- 清单：manifest.json 保留原始相对路径、字节数、SHA256与来源；RuntimeAssets.props 为可复现打包清单。NOTICE.md 保留荣耀归属。
- 生成：`D:\python\python.exe tools/dev/generate-honor-icons.py`，只读本目录，验证全部哈希并重建C++资源头文件、应用映射和打包清单。仅第一次导入使用 --import-from；不会在日常构建中扫描外部目录。
- 后续新增图标：把原件作为普通文件收入library，审查来源并更新manifest、准确应用别名或模块映射，再生成与构建；现有应用无需再逐个硬编码文件路径。
- 系统兜底：Windows Shell 图标接口优先请求128px，窗口或EXE资源作为后备；在原有后台STA执行，不加载Python、不把低分辨率图片强行放大。快捷方式只读取，不调用可能弹窗或修改链接的Resolve。自定义图像保留，两个套装使用已有设计原件，不把“白底”误转成灰白滤镜。
- 内存：PNG按实际尺寸解码，单边不超过256px；桌面、文件夹和所有bar共用一个48纹理/4MiB缓存。套装切换、图形设备恢复与退出释放。无新增轮询、WebView或动画。
