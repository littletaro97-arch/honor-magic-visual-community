# 荣耀magic视界社区复刻

面向 Windows 的社区桌面项目发行与更新仓库。

本仓库用于发布安装包、版本说明及后续客户端更新。项目为社区复刻与维护项目，非荣耀官方产品。

## 下载与版本

请在 [Releases](https://github.com/littletaro97-arch/honor-magic-visual-community/releases) 页面查看后续发布的版本、安装包和更新说明。

仓库目前处于初始化阶段，尚未上传安装包。开发与验收版本将在发布时标记为 **Pre-release**，请按每个版本的说明选择使用。

## 更新渠道

后续版本计划通过 GitHub Releases 提供。客户端自动检查更新的接入状态、安装方式及兼容要求，以实际发布说明为准。

## 问题反馈

反馈时请提供版本号、Windows 版本、复现步骤，以及必要的截图或脱敏日志。请勿提交访问令牌、证书私钥、账号信息或包含个人内容的完整运行数据。
